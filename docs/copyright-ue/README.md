```bash
python docs/copyright-ue/gen-ue-copyright.py
```

输出到 `E:\ppt\GramStain软著\`：源程序 60 页、说明书 4 页、申请表填写内容、材料清单。

工程路径：`E:\ue5.8\3.0\GramStain`（Unreal Engine 5.8）

## 这个项目和比邻AI的差别：源程序从哪来

UE 项目的核心交互逻辑在**蓝图**里，蓝图是二进制 `.uasset`，没法打印成文本。
工程里可打印的自有代码只有 73 个 Python 脚本（资源生成、文案批量替换、
翻译表导入、编辑器 MCP 桥接），分块后 6207 行，取前 1500 + 后 1500 组成 60 页。

说明书里如实写了"交互逻辑用蓝图实现"，没有假装是 C++ 工程。

## 两个踩过的坑

**1. 超长行必须按显示宽度分块，不是按字符数**

代码里有中文注释，一个汉字占两个半角宽。最初按 175 字符分块，结果行仍然折行，
一页装不下 50 行，页数从 60 变成 64，中间出现只印 1–2 行的残页。

改成按显示宽度（半角 1、汉字 1.7）分块，上限 115 单位后，实测 60 页、逐页 50 行。

**2. 换页不能用"插入分页符段落"**

插一个含 `add_break(WD_BREAK.PAGE)` 的空段落来换页，这个段落本身占掉当前页一行，
把 50 行/页顶成 51 行。改用 `paragraph_format.page_break_before = True` 后正常。

## 插图怎么来的

工程里只有 PIE 运行截图和资源图，没有专门的界面截图。做法：

  · 从 `Tools/Lang/截图/` 的四张 PIE 截图里裁掉 Unreal 编辑器边框
    （左 6px、上 155px、右 1090px、下 810px），只留游戏画面；
  · 显微镜 40×/100× 视野图取 `Tools/Micro/out/T_Micro_*.png`，缩到 1200px 宽；
  · 说明书里用**浮动环绕**（靠右、文字绕左），不是嵌入型 ——
    嵌入型独占整行高度，带图的页面到不了"每页 30 行"。

## 截图是真正在 UE 里抓的

用编辑器自带的 Python 远程执行（Config 里 bRemoteExecution=True）启动 PIE，
再用窗口截图抓画面。三个坑：

1. **150% DPI 缩放**：不声明 DPI 感知时 GetWindowRect 返回逻辑像素，
   截图会偏移并带上一截桌面。要先 SetProcessDpiAwarenessContext。
2. **PrintWindow 而不是 CopyFromScreen**：UE 视口是 D3D 渲染，
   CopyFromScreen 常拿到黑块；PrintWindow(flag=2) 由窗口自己画到内存 DC。
3. **PowerShell 对 P/Invoke 的 out 结构体不可靠**：矩形查询、点击、截图、
   保存全部移到 C# 方法里，PS 只传参。

裁切：1600x960 窗口里 PIE 视口为 (6,192)-(1150,817)，
去掉左侧细工具栏、顶部菜单与视口工具条、右侧大纲/细节、底部内容浏览器。

## 版式约束

否则嵌入图独占整行高度，带图的页面到不了 30 行。
