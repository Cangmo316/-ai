# 软著申请材料生成器

按中国版权保护中心的要求，用仓库里的代码自动生成软著材料。

依据（官方原文）：[中国版权保护中心 · 所需文件](https://www.ccopyright.com/index.php?optionid=1080)

> 程序和文档的鉴别材料应当由源程序和任何一种文档前、后各连续 30 页组成。
> 整个程序和文档不到 60 页的，应当提交整个源程序和文档。
> **除特定情况外，程序每页不少于 50 行，文档每页不少于 30 行。**

## 为什么用脚本而不是手排

三条硬要求手工排版几乎必错：

| 要求 | 手工排版的坑 |
|---|---|
| 程序每页 ≥50 行 | 一条长代码折行，这页就装不下 50 行，页数跟着变 |
| 前 30 页 + 后 30 页共 60 页 | 手数容易错，且删改后要重数 |
| **文档每页 ≥30 行** | 截图一放就挤掉文字，行数不达标 |
| 三份材料的软件名称与版本号逐字一致 | 改一处忘一处，直接被要求补正 |

## 用法

`ash
python docs/copyright/gen-source-and-manual.py      # 源程序 + 说明书
python docs/copyright/gen-form-and-checklist.py     # 申请表填写内容 + 材料清单
`

改软件名称或版本号：两份脚本顶部的 SOFTWARE_FULL / SOFTWARE_VERSION 要一起改。

## 踩过的坑（改脚本前必看）

1. **必须排除第三方库**。uni-app/libs/three/* 与 static/draco/* 是他人代码
   （35,000+ 行），混进源程序会被认定"含他人已登记代码"。
2. **.md 文档不能当源码收进去**。中文长句折行，撑破 50 行/页。
3. **图片段落必须单独设单倍行距**。Normal 是固定行距，Word 会把内嵌图片
   **裁到一行高**（表现：21 页说明书被压成 4 页）。且设完
   line_spacing_rule = SINGLE 后**不能再写** line_spacing = None，
   那句会把刚设的规则清掉。
4. **文档每页 ≥30 行是最难的一条**。手机截图高宽比约 1:2.2，一张图占约 20 行版面；
   19 张图就把每页文字压到 16 行。换算关系是：
   文字行数 ≥ 图片张数 × 每张占行数，否则页数变多而每页行数达不到 30。
   最终方案：图缩到 3.6cm 内联、只留 6 张、正文按操作步骤写厚。
5. **页数必须实测**：Word Repaginate() 后 ComputeStatistics(2)，
   不能靠算行数或 PDF 文本抽取（空行与图片会导致抽取失真）。
6. **不要加"此处省略"说明行**：1 行说明会把 3000 行顶成 3001 行、页数变 61。

## 线上表单的字数限制：50 **字节** 不是 50 字

开发与运行环境那几个输入框限 50 字节。按 UTF-8 一个汉字 3 字节，
**50 字节只够约 16 个汉字**。按"写满一行中文"的习惯填，提交时会被截断或报错。

脚本里给了压缩后的值，并把字节数画进表格第三列，同时加了断言：

`python
for field, value, _full in env_rows:
    if len(value.encode("utf-8")) > 50:
        raise SystemExit("字段「%s」超 50 字节" % field)
`

|---|---|---|

| 运行的硬件环境 | 2核2G服务器；Android 8.0手机 | 35 |

| 该软件的运行平台 / 操作系统 | Ubuntu 22.04;Windows 10;Android 8.0 | 35 |
| 软件运行支撑环境 / 支持软件 | Python 3.11;FastAPI;SQLite 3 | 28 |

另外两条容易忽略：源程序量按纯数字填（不要千分位逗号）；软件名称不得含
"中国""国家""国际"等字样。

## 还有一个坑：WPS 占用会导致生成失败

若生成时报 PermissionError: ... 01-....docx，说明该文件正被 WPS/Word 打开。
两个办法：关掉文档后重跑；或把 OUT 指到另一个目录生成（gf.OUT = 新目录）。
## 开发目的 / 面向领域 / 主要功能 / 技术特点 的字节限制

实测这几栏在线表单同样卡字节数，「开发目的」限 50 字节（约 16 个汉字）。
原先写的 552 字节，是限制的 11 倍，提交必被截断。

脚本给的是可直接抄的值，字节数已画进表格并加断言：

| 字段 | 填写值 | 字节 / 上限 |
|---|---|---|
| 开发目的 | 为独居老人提供智能陪伴与健康管理 | 48 / 50 |
| 面向领域 | 智慧养老与家庭健康管理领域 | 39 / 50 |
| 主要功能（50 字节版） | 陪伴、健康档案、用药提醒、家属 | 45 / 50 |
| 主要功能（200 字节版） | 语音文字对话并自动切换双人设；记录血压血糖体重与趋势；病历拍照结构化归档；用药与日程提醒；主动关心与回访；家属绑定远程查看 | 183 / 200 |
| 技术特点（50 字节版） | 双人设自动切换、医疗合规兜底 | 42 / 50 |
| 技术特点（200 字节版） | 双人设分层路由与医疗合规三重兜底；分层长期记忆；历史按频次压缩；关心调度受频次与静默约束；模型语音可本地切换 | 162 / 200 |

**为什么要给两档**：主要功能/技术特点的限制各批次不同（有 50 字节的，也有按字数的）。
先按 50 字节版填；表单允许更多时再换 200 字节版。

详细版（11 条功能、7 条特点）保留在「四之一、详细版」，标注了"不要填入表单"——
写说明书、向评审解释时要用。

## 生成时遇到文件被 Office 占用怎么办

`regen-copyright.py` 已处理：先写临时目录，再尝试覆盖；被 WPS/Word 占用时
自动另存为 `原名（最新）.docx`，不中断、不丢结果。

```bash
python docs/copyright/regen-copyright.py               # 四份全出
python docs/copyright/regen-copyright.py --only form    # 只出申请表
```
