# 材质：压金属度治"反光太强"（2026-10-05）

> 用户反馈：「材质金属度调低，反光太强了」。
> 结论：**资产自带的金属度贴图确实偏高**，而且这是卡通角色的皮肤与布料，
> 物理上金属度应接近 0 —— 直接归零，并把粗糙度乘 1.2 让高光更散。

---

## 1. 实测：金属度到底有多高

资产自带的 metallic 贴图，导出后与 roughness **打包进同一张 ORM 图**
（glTF 规范：R = 环境光遮蔽、G = 粗糙度、B = 金属度）。
逐通道量分布（256² 重采样）：

| 通道 | 男医 | 女医 | 含义 |
|---|---|---|---|
| R | 1.000 | 1.000 | 环境光遮蔽 |
| G | 0.469 | 0.526 | 粗糙度 |
| **B** | 0.259 | **0.374（33.8% 的像素 > 0.5）** | **金属度** |

而材质里 `metalness = 1`（× 贴图）→ **女医有近三分之一的表面被当金属渲染**，
这就是"反光太强"的直接来源。

**顺带发现一个 three r160 的坑**：glTF 里 `metalnessMap.channel` / `roughnessMap.channel`
**都是 0**（规范应为 2/1），说明 r160 **不支持 ORM 打包图的 `texture.channel`**，
两个采样器其实都读 G 通道（粗糙度）。所以**压金属度只能改材质的 `metalness`**，
改不动采样通道 —— 这也解释了为什么"金属度看着没生效"。

---

## 2. 标定（真渲染器离屏取像素，女医交付件 + 半身取景）

| 金属度 | 粗糙× | 平均亮度 | 反光面积(>200) | 过曝(>240) | 高光集中度 |
|---|---|---|---|---|---|
| **1（资产原值）** | 1.0 | 48.4 | 0.22% | 0.083% | 203 |
| 0 | 1.0 | 59.1 | 0.10% | 0.045% | 173.5 |
| **0（采用）** | **1.2（采用）** | **58.2** | **0.01%** | **0.006%** | **123.6** |
| 0 | 1.5 | 57.1 | 0.01% | 0.006% | 105.9 |
| 0 | 1.8 | 56.1 | 0.01% | 0.004% | 101.3 |
| 0 | 2.2 | 55.1 | 0% | 0% | 94.8 |

**取「金属 0 + 粗糙×1.2」**：过曝从 0.083% 降到 **0.006%（1/14）**、反光面积 0.22% →
**0.01%**，而平均亮度**不降反升**（48.4 → 58.2，因为金属度归零后漫反射回来了）。
再往上加粗糙度过曝不再降、脸开始发灰（57.1 → 55.1），没有收益。

## 3. 落地

| 改动 | 说明 |
|---|---|
| 新增 `stage.setMaterial({ metalness, roughnessScale })` | 运行时改材质（金属度直接覆盖、粗糙度按倍数乘贴图） |
| 新增 `DEFAULT_MATERIAL = { metalness: 0, roughnessScale: 1.2 }` | **出厂值**，写在渲染器里，两个页面自动生效 |
| `load()` 里在**挂上模型前后各施加一次** | 材质是每模型的：load 前设好避免闪一帧，load 后重设避免换模型丢校正 |
| 形象页也改半身取景 | 用户要在形象页比较男女差异，只看头看不出衣服（白大褂） |

**为什么不改资产、只在端侧改**：金属度是**渲染参数**不是几何数据，
端侧一行设置即可，不必重新跑导出管线；而且同一副资产在不同页面可能需要不同观感。
