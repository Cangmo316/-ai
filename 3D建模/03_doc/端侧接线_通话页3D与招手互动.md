## 2. 踩到的两个坑（都已修）

### 2.1 画布用 `height:100%` 参与 flex 布局 → 把底部按钮顶出视口

`canvas.style` 原来是 `width:100%;height:100%`（**参与宿主的 flex 布局**）。
通话页是"100vh 竖向 flex + 底部按钮"，100% 高的画布加上 `min-height` 会把页面撑高
（实测总高 816 > 视口 485，按钮跑到 `bottom:1112`）。

**修法**：画布改 `position:absolute;left:0;top:0` 铺满宿主，宿主高度完全由 CSS 决定；
同时舞台容器必须 `position:relative`（否则画布会相对更外层定位、盖住整屏 UI），
并把舞台 `min-height` 调小。

### 2.2 CDP 的浏览器窗口状态会坏，别依赖它

本轮 HBuilderX 的 CDP 一度只剩 `devtools://` 一个页面（`shot`/`eval` 全部失效），
重启 HBuilderX 期间又踩到**「必须先 `cli open` 把主程序拉起来，`cli launch web` 才认」**
（否则报"未检测到已打开的 HBuilderX"），且 `Start-Process` 起的方式会因为父进程退出而**连带退出**。

**可用的替代验证手法（记下来备用）**：
1. `cli open` → 等 30~40s → `cli launch web`（**用后台作业常驻**，不要 `Start-Process`）；
2. 若 CDP 仍不可用，**起一个无头 Edge 自己的调试端口**：
   `msedge --headless=new --remote-debugging-port=9600 --user-data-dir=<临时目录>`，
   然后 `$env:HX_CDP_PORT='9600'; node tools/hx-cdp.mjs shot/eval …`
   —— 完全绕开 HBuilderX 的窗口，且能正常 `eval` 页面上下文。
