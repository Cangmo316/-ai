# 通话页：全身取景 + 镜面强度可调（2026-10-05）

> 用户反馈两条：**① 数字人只有一个头；② 还是太油腻。**

---

## 1. 为什么"只有一个头"——不是资产问题，是**取景盒本来就是按头算的**

`computeFocus()` 的取景盒一直是"头部"档：注释写得很清楚，那是**捏脸页**的需求
（滑杆只作用在脸上，全身构图时脸只有几十像素，拖了也看不出变化）。
但通话页直接复用了同一个渲染器，于是**沿用了头像取景**——看起来就像"只有一个头"。

**修法**：给取景加模式，两个页面各取所需。

| 模式 | 取景盒 | 用在 |
|---|---|---|
| `head`（默认，保持既有行为） | 头顶往下、含脖肩 | 捏脸页 |
| **`body`（新增）** | **整个静止姿态包围盒 ×1.06** | **通话页** |

实测对比（Q 版女医交付件）：

| 模式 | 焦点盒尺寸（x, y, z） | 中心 y |
|---|---|---|
| `head` | 0.5917, **0.7326**, 0.5579 | 1.024 |
| **`body`** | 0.8320, **1.2236**, 0.5294 | **0.5613** |

`body` 的 y 跨度 1.2236 ≈ 模型身高（1.1544 + 边距），中心落在半身高度 —— 即**全身入框**。

调用方式（两个页面都改了，App 端 renderjs 与 H5 两条路径都走）：
```js
stage.load(gender, 'delivery', { frameMode: 'body' })
```
`frameMode` 也参与 `load()` 的幂等判断——同一个资产在两种取景下都要能重建构图。

## 2. "还是太油腻"——上一轮我压错了变量

**上一轮的做法是错的**：我把**解析灯整体降到 0.8×** 来压高光，
但那**同时压暗了漫反射**（脸整体发灰），而"油"只来自**镜面项**。
所以用户仍觉得油，而脸还变暗了。

**这一轮改成只压镜面**：新增 `stage.setSpecular(倍数)`，只缩环境贴图对镜面项的贡献，
**完全不碰漫反射**（所以压高光不会把脸调暗）。

### ⚠️ r160 的坑：`scene.environmentIntensity` 不生效

`debug().material.envMapIntensity` 始终是 1（该属性由 `scene.environmentIntensity` 赋值），
场景里也没有 `USE_ENVMAP` 宏 —— 实测确认 **three r160 上 `scene.environmentIntensity` 不起作用**。
`MeshStandardMaterial.envMapIntensity` 是**每材质**生效的，所以代码按版本分叉：

- r161+：用 `scene.environmentIntensity`（`supported: true`）
- **r160：逐个材质写 `envMapIntensity`**（`supported: false`，本仓库走这条）

并且 `setSpecular` 必须在**每次挂上新模型之后**重新施加（材质是新的，值会丢）。

### 标定（全身取景，真渲染器离屏取像素）

| 镜面倍数 | 平均亮度 | 高光集中度 | **>200 的"油光面积"** | 过曝 |
|---|---|---|---|---|
| ×1.00 | 91.5 | 163.5 | **11.7%** | 0.588% |
| ×0.80 | 78.3 | 176.7 | 1.90% | 0.268% |
| ×0.65 | 68.3 | 186.7 | **0.35%** ← 断崖 | 0.247% |
| **×0.55（采用）** | ≈62 | ≈192 | **≈0.32%** | ≈0.20% |
| ×0.50 | 58.2 | 196.8 | 0.31% | 0.186% |
| ×0.40 | 51.6 | 203.4 | 0.28% | 0.175% |

**取 ×0.55 的理由**：`>200` 的像素占比从 11.7% 断崖式降到 0.3% 量级
（那 11.7% 的大面积柔光就是"油"的观感来源），而平均亮度还保留 62；
再往下压收益极小（0.32% → 0.28%）却明显把脸调暗。

**注意**：`集中度` 这个指标在压镜面时会**反而升高**（163.5 → 203.4）——
因为镜面被压掉后，图里剩下的最亮点变成更小更锐的高光点。
所以"集中度"只在**比较同一镜面档位下的环境贴图/法线差异**时才有意义，
**判"油不油"要看 `brightPct`（大面积亮区占比）**。这一步我一开始也看错了指标。

## 3. 现在的可调接口（不用改代码就能定观感）

| 接口 | 作用 |
|---|---|
| `stage.setSpecular(×倍数)` | **治油亮的正确那一刀**：只压镜面，不动漫反射。`0` = 完全无镜面，`1` = 默认 |
| `stage.setLighting(环境强度, 解析灯倍数)` | 调整体光照（会同时影响漫反射，慎用） |
| `stage.measureShading(size)` | 读 `meanLuma / concentration / brightPct / blownPct` 判观感 |
| `stage.load(gender, role, {frameMode})` | `'head'` 头像取景 / `'body'` 全身取景 |

## 5. 第三轮：全身仍"人太小" → 改为**半身取景 + 收紧构图**

用户反馈：「人物太小了」（并再次确认形象应换成男医/女医 —— 这一点**资产本身没问题**：
`AVATAR_DELIVERY_ASSET` 指向的就是从 `3D建模/男医`、`3D建模/女医` 导入后重绑的
`BilinAI_{Male,Female}FaceRig_60k_delivery_baked.glb`，6.4MB / 6.3MB，Draco 版）。

**全身取景本身就偏小**：可见高度 ≈2.18 而角色身高 1.1544 → 只占画面高度约 42%。
全身"完整"和"看得清"在竖屏通话页里是矛盾的，通话场景本就该是**半身/胸像**（和视频通话一样）。

### 新增第 3 种取景 + 可配构图松紧

| 模式 | 取景盒 | 用在 |
|---|---|---|
| `head` | 头顶往下含脖肩 | 捏脸页 |
| **`bust`（新增，通话页采用）** | 静止姿态包围盒**胯以上**（y ≥ min + 38%），高度约占身高 60% | 通话页 |
| `body` | 整个包围盒 ×1.06 | 需要在画面里看完整站姿时 |

同时把**构图松紧**做成 `load(..., {fitMargin})`（原来写死 `FIT_MARGIN = 2.2`，
那是**捏脸页**调出来的：预览区是横的、且要留头部转动余量）。
通话页用 `fitMargin: 1.15`。

### 客观标定（新增 `stage.measureSilhouette(size)`）

新增度量口子：渲染到离屏目标，取**不透明像素包围盒**，返回宽高占画布的百分比 ——
这是"人太小/太大"唯一客观的判据（肉眼估会在两个方向之间来回摇摆，**实测已经走了两轮**：
"只有一个头" → "全身" → "半身"）。

| 取景 | 占画面宽 | 占画面高 | 不透明填充 |
|---|---|---|---|
| body, fit 2.2（上一轮交付的） | 29.2% | **42.2%** | 6.6% |
| body, fit 1.15 | 55.7% | 81.8% | 24.4% |
| bust, fit 2.2 | 42.2% | 62.2% | 14.1% |
| bust, fit 1.5 | 62.5% | 78.1% | 27.0% |
| **bust, fit 1.15（本轮采用）** | **81.8%** | **86.7%** | 39.1% |
| bust, fit 1.0 | 94.3% | 92.4% | 48.0% |

取 `bust + 1.15`：人物占高 86.7%，基本撑满画面且四边仍有余量（不会一转头就出框）。

### 经验教训

"取景"这件事在本项目里已经改了三轮（头 → 全身 → 半身），每次都是凭感觉调。
**从这一轮起先跑 `measureSilhouette` 再改**：目标区间是**占高 85%~92%**。
