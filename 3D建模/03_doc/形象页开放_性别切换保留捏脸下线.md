把编辑块（分区 chips / 摘要 / 滑杆 / 操作按钮 / 分区操作）整体挂 `v-if="FACE_EDIT_ENABLED"`。
**将来接回捏脸只需把常量改回 `true`** —— 滑杆目录、接线、参数表都还在，不用重写。

## 2. ⚠️ 关键修复：切了性别"带不过去"

之前的"切性别不生效"根因是：**性别只存在形象页的局部 `ref` 里**，
切完进通话页又回到默认值 —— 用户看到的还是原来那个形象。

**修法：把性别提到全局 store**（`uni-app/common/store.js`）：

| 改动 | 说明 |
|---|---|
| `settings.gender`（初值 `''` = 未选过） | 全局唯一的形象性别 |
| `setGender(value)` | 写 store + 落本地存储 `bl_gender`，重启后仍生效 |
| `initSettings()` 恢复 `bl_gender` | 已在 `App.vue` 启动时调用 |
| 形象页 `gender` 改为 `computed(() => settings.gender \|\| DEFAULT_GENDER)` | 以全局为准，只做兜底 |
| 形象页 `switchGender()` 改为调 `setGender()` | 切换即持久化 |
| **通话页 `gender` 也改为 computed + 加 `watch(gender)`** | 别处切了性别，回到通话页自动换模型 |

## 3. 实测（无头 Edge + `hx-cdp`）

**形象页内容**（`document.body.innerText`）：
```
数字人形象 | 3D 实时预览 · 可旋转 | 本形象为 AI 数字人 | 基于本人授权素材生成，不是真人实时画面
| 左右拖动可旋转视角 | 形象 | 女性 | 男性 | 此功能正在开发中
| 精细调整五官的功能还在做，先上线形象切换 | 上面选「女性 / 男性」即可切换数字人形象
```
—— 有性别选择与开发中提示，**没有滑杆**。

**性别切换闭环**（点按钮 → 看舞台实际加载的资产 + 本地存储）：

| 操作 | 舞台 gender | 实际加载 | `localStorage.bl_gender` |
|---|---|---|---|
| 初始 | male | `..._MaleFaceRig_60k_edit.glb?v=3` | （未设置，兜底 DEFAULT_GENDER） |
| 点「女性」 | **female** | `..._FemaleFaceRig_60k_edit.glb?v=3` | `female` |
| 点「男性」 | **male** | `..._MaleFaceRig_60k_edit.glb?v=3` | `male` |

**跨页生效**（形象页选「女性」→ 打开通话页）：
```
gender=female  asset=BilinAI_FemaleFaceRig_60k_delivery_baked.glb?v=3  bones=14  占画面高 93.2%
```
即：**在形象页选性别 → 通话页自动用对应形象**，这就是用户要的"能换男女形象"。

`npm test` 全绿；`npm run test:face` 20/20。
