# 比邻AI · App 原型 V1

依据 `比邻AI_UI设计流程与提示词.md` 制作。定位：微信风格 + 亲友陪伴 + 适老化 + 3D 数字人。

## 怎么看

双击 `prototype/index.html` 即可，纯静态、无需服务器。

- 顶部工具栏可直接跳转任意页面
- `#hash` 深链：`index.html#chat`、`#vision`、`#face` …
- `?large=1` 打开大字体模式：`index.html?large=1#chat`
- 也可以点手机里的 TabBar、返回箭头、按钮走完整流程

## 交付物

| 文件 | 说明 |
|---|---|
| `prototype/index.html` | 原型主文件，11 个页面 |
| `prototype/styles.css` | 设计 Token（CSS 变量）+ 全部组件样式 |
| `prototype/app.js` | 页面路由、通话计时、捏脸滑杆、日历生成等交互 |
| `prototype/tokens.json` | 设计 Token 表，给 uni-app 前端对齐命名用 |
| `_shots/` | 各页面渲染截图（Edge 无头生成） |

## 页面清单（11）

1. 启动页 — 渐变背景 + 发光环数字人 + 开始使用
2. 会话列表页 — 三条会话、未读角标、TabBar
3. 聊天详情页 — 左右气泡、语音条、表情面板、输入栏
4. 视觉模式页 — 3D 数字人通话、计时、实时字幕、通话控件
5. 今日计划页 — 用药/午餐/散步/问候四张卡片 + 打卡状态
6. 日历视图 — 月视图 + 计划日标记 + 今日高亮
7. 我的页 — 头像资料 + 陪伴设置 + 健康与设置
8. 智能体角色选择页 — 三个 AI 亲人角色卡、选中态
9. 3D 捏脸页 — 实时预览 + 8 项参数滑杆 + 保存/随机
10. 空态页 — 首次使用无消息
11. 设计规范页 — 色彩 / 适老化基准 / 评审自查清单

## 可交互的部分

- TabBar 三 Tab 切换，聊天页 → 视觉模式 → 挂断回到聊天
- 会话列表 → 聊天详情；我的 → 角色选择 / 捏脸
- 捏脸滑杆实时改变预览（脸型、肤色、发型、年龄感、服饰真的会变）
- 通话计时从 00:42 起真实走秒；静音/扬声器按钮可切换状态
- 日历点任意日期给出当日计划提示
- 大字体模式：工具栏开关 或 我的页开关，正文 16px → 20px

## 设计 Token

`styles.css` 顶部 `:root` 是唯一数据源，`tokens.json` 是同一份值的导出。
改一处即可全局生效——例如把 `--color-primary` 改掉，所有按钮、气泡、TabBar 一起变。

适老化硬指标已写进实现：正文 ≥16px、可点元素 ≥48px、圆角 气泡12/卡片16、8pt 栅格。

## Figma 侧现状

Figma 连接是通的，但当前 **Starter 套餐 + View 席位** 有三道硬限制，原型没法完整在 Figma 落地：

| 限制 | 实际影响 |
|---|---|
| MCP 工具调用 20 次/月 | 建完变量和启动页后额度用尽，无法继续写画布 |
| 变量集只能 1 个模式 | 「大字体模式」不能做成变量模式，改为独立变量 |
| 最多 3 个页面 | 页面地图 / 组件库 / 页面 三页封顶 |

已在 Figma 文件 `比邻AI · App UI 原型 V1`（`zWpt5xqLHIgGkwMhoHR0Po`）落地的部分：

- 3 个页面：`01-规范与地图`、`02-组件库`、`03-页面`
- `比邻AI / 色彩` 变量集：11 个色彩变量
- `比邻AI / 尺度` 变量集：20 个尺度变量
- 启动页高保真稿（375×812）

升级到 Dev/Full 席位后（200 次/天），可以按同样的 Token 把其余 10 个页面写进 Figma。
