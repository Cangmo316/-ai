三、三条隐私硬约束（写进 AGENTS 了，别拆）
--------------------------------------------------------------------------------
1. `source=auto`（从聊天自动整理）的记忆 **visibleToFamily=false**：
   `scope=family` 不返回。否则"家人端默认看不到聊天原文"会被记忆绕过去
2. `review=pending`（置信度 < 0.75）**不参与检索、不用于主动话题**，只等家属复核
3. `autoExtract` **默认关**（开启才记 consentedAt=已告知本人）；
   **端侧不提供记忆写入入口**——写入只能走家人端或对话自动整理

四、本轮踩到的坑 / 修掉的缺陷
--------------------------------------------------------------------------------
1) **service.generate() 没给 elder_id 时，L1 档案与记忆全静默丢失**
   generate(elder_id=None) → elder_profiles.get(None)=None → prompt 里既没有档案
   也没有记忆，表现是"智能体突然不记得我是谁"。已加 `elder_id or DEFAULT_ELDER_ID`。
   （HTTP 层一直在传，所以线上没暴露；这是"少传一个参数就静默降级"的典型）

2) **中文分词停用词规则过狠**：原实现把含停用字的二元组全砍掉，
   于是"去过""去年"这类**承载事实的关键词**被切没了 → 经历类记忆检索不到。
   改成"二元组只要有一个字不是停用字就保留"。

3) **空文本走错错误码**：登记了 `memory_empty`(400) 却返回 `invalid_request`(422)。
   端侧 422 的文案是"请求失败（422）"，不符合"老人看得懂"的约定。

4) 测试自身的坑（已记在用例注释里）：
   - 端侧 `request()` reject 的是 **{code,statusCode,message,retryable} 对象**（不是
     Error），且 4xx 的 message 被端侧改写成老人话术 → 断言口径必须是 code
   - 用例不能在收尾 `process.exit()`（Windows 上撞 libuv 的 UV_HANDLE_CLOSING 断言），
     要 `await mock.close()` 后只调 `finish()`（它设 process.exitCode）
   - 用例不能依赖 mock 的种子数据（真服务是空库）→ 改成"缺什么补什么"

五、明确的遗留（下一步按此顺序）
--------------------------------------------------------------------------------
1. **记忆落 PostgreSQL**：现在全内存，进程重启即清空（会话/计划/打卡/提醒/cid 同样）
2. **家人端的记忆录入/复核页**：接口与隐私口径已就绪，`family/` 里还没有这个页面
3. **记忆检索向量化**：现在是"标签/词组重合 + 时间衰减"（零依赖、可解释）。
   记忆量到几千条再换 embedding；入口只有 `retrieval.py::score()` 一处
4. **模型的"添油加醋"要收一收**：实测回答里出现了记忆中没有的细节
   （"那会儿你天天发照片 晒得可开心了"）。prompt 已写"绝不要编"，但还不够，
   建议：给记忆注入加一句"只说记录里写到的事，细节不确定就不提"，
   或加一条合规扫描（检测回答里出现记录外的具体事实）

七、另一条线：Android 真机（未完成，与记忆无关）
--------------------------------------------------------------------------------
- 模拟器：API 34 x86_64 上标准基座白屏，根因是基座按 ABI 挑了
  `arm64-v8a/libweexjsb.so`（Android 14 的 x86_64 模拟器对外宣称支持 arm64），
  ARM 库加载失败 → WeexCore IPCException → 逻辑层起不来。**不是项目代码问题**。
  换 API 30 x86 后逻辑层正常，但 HBuilderX 的 CLI 不肯把运行下发到第二台设备，
  手工 adb push 又缺 HBuilderX 同步时写的状态（基座把项目当 5+ 项目，加载报
  "请求的页面无法打开"）。
- 真机（荣耀 WIN RT）：USB 调试开着，但手机侧 adbd 没监听（只暴露了荣耀自家
  HDB 通道），adb 枚举不到设备。**下一步建议走无线调试**（开发者选项 → 无线调试
  → 使用配对码配对），我这边 `adb pair` + `adb connect` 即可接手。
